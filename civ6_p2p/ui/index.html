联机使用说明

适用场景：零服务器成本、延迟最低。适合双方（或房主端）拥有公网 IPv6，或处于普通家庭宽带（Cone NAT）可 UDP 打洞的网络环境。

快速联机步骤

  1. 配置身份并启动节点：房主在顶部选「房主」、好友选「加入者」，填写昵称与相同的房间口令（默认端口 38666），点击 启动节点。
  2. 选择对外地址：顶部显示「IPv6 公网就绪」时，在「本机对外地址」优先选择 [首选公网 IPv6]；若没有公网 IPv6，可点击 STUN 公网检测 探测公网 IPv4 映射端口。
  3. 互换连接码并打洞：点击 复制我的连接码 发给好友；双方都在「对方连接码 / IP」中粘贴对方连接码并点击 添加并连接 / 打洞（双方互填可同时双向打洞，穿透率更高）。
  4. 连通测试解锁第二步：成员列表变为「在线」且在线人数 ≥ 2 后，选中好友点击 测试选中连接（校验延迟与 1150B 大包），通过后自动解锁 第二步 · 文明6 联机辅助。

常见问题排查

  • 一直显示「打洞连接中」：核对双方「房间口令」完全一致、双方均已添加对方地址，并在 Windows 防火墙弹窗中放行本程序 UDP 访问。
  • 仍无法直连：若双方均为对称 NAT、移动数据热点、校园网或严格企业网且无公网 IPv6，请切换至 方式二 · 自定义 VPS 中继。
适用场景：无公网 IPv6、对称 NAT、校园网或跨运营商直连丢包严重时，通过自建云服务器（VPS）自动中继或辅助打洞，无需互换 IP 即可同房互见。

方案一 · EasyTier 自建 VPS 节点（推荐，默认端口 11010）

客户端已内置 EasyTier 无虚拟网卡核心，会优先尝试 P2P 打洞，打洞不通自动经 VPS 中继。请先在云服务器安全组与系统防火墙放行 TCP / UDP 11010。

Linux / VPS 启动命令（已下载 easytier-core）
./easytier-core --no-tun -l tcp://0.0.0.0:11010 -l udp://0.0.0.0:11010
Docker 一键部署命令
docker run -d --name easytier --restart always --network host easytier/easytier:latest --no-tun -l tcp://0.0.0.0:11010 -l udp://0.0.0.0:11010

部署后点击 + 添加 VPS → 类型选 EasyTier VPS (11010) → 地址填写 tcp://你的VPS公网IP:11010（也支持 udp:// 或逗号分隔多个备用节点）。

方案二 · 轻量 UDP 中继（civ6_relay_server，默认端口 38668）

零第三方依赖，仅需 Python 3 即可在 VPS 运行，同时支持 IPv4 / IPv6 客户端混合接入。请在云服务器安全组放行 UDP 38668。

上传 civ6_relay_server.py 与 civ6_p2p 目录到 VPS 后运行
python3 civ6_relay_server.py --port 38668

部署后点击 + 添加 VPS → 类型选 轻量 UDP 中继 (38668) → 地址填写 你的VPS公网IP:38668（支持域名或 [IPv6]:38668）。

客户端连接步骤

  1. 房主在顶部选「房主」、好友选「加入者」，填写相同的「房间口令」。
  2. 在「方式二 · 自定义 VPS 中继」中选中同一自建 VPS 节点并填写相同的「房间名」，点击 连接 VPS 房间。
  3. 待成员列表出现好友并显示「在线」后，点击 测试选中连接，测试通过即可进入第二步开启文明 6 联机辅助。
+

添加自定义 VPS 节点

支持 tcp://ip:11010、udp://ip:11010、ip:11010，或多个备用 VPS 用逗号分隔；未填端口默认 11010。
