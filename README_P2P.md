# CV6 online helper

基于 [Frwere/civ6-l3-discovery-helper](https://github.com/Frwere/civ6-l3-discovery-helper) 重构扩展的文明 6 联机助手，免管理员权限、免创建虚拟网卡、免注入游戏进程。

## 两大联机方式

1. **方式一 · IPv6 / P2P 直连**：支持公网 IPv6 直连、双向 UDP 打洞与 STUN 公网检测，无需服务器、延迟最低。
2. **方式二 · 自定义 VPS 中继**：支持添加并持久化保存您自己的 VPS 中继节点（已移除所有公益节点）：
   - **EasyTier 自建 VPS 节点**（内置 `easytier-core --no-tun`，无虚拟网卡，如 `tcp://你的VPS:11010` / `udp://你的VPS:11010`），自动尝试打洞并在严格 NAT 下走 VPS 中继；
   - **轻量 UDP 中继 VPS 节点**（运行 `python3 civ6_relay_server.py --port 38668`，填入 `你的VPS:38668`），零依赖、低延迟转发。

## 严格两步式联机流程

### 第一步：建立连接并测试连通（至少 2 人在线）

1. **双方**运行 `CV6 online helper.exe`（或 `py civ6_p2p_helper.py`）。
2. 选择本机角色（`房主` / `加入者`）、填写昵称与相同的 **房间口令**，点击 **启动节点**。
3. 选择联机方式：
   - **方式一（IPv6 / P2P 直连）**：复制自己的连接码发给好友，在「对方连接码/IP」中粘贴对方的连接码并点 **添加并连接 / 打洞**。
   - **方式二（自定义 VPS 中继）**：点击 **+ 添加 VPS** 录入自建 VPS 节点（EasyTier 或 `civ6_relay_server`），双方选择同一 VPS 节点并填入相同的 **房间名** 与 **房间口令**，点击 **连接 VPS 房间** 即可自动发现对方。
4. 顶部在线人数显示 **在线: 2 人（或以上）**、成员列表显示 **🟢 在线** 后，选中好友点击 **测试选中连接**（验证延迟与 1150B 大包）。
5. **只有测试连接成功且当前至少 2 人在线时**，「第二步 · 文明6 联机辅助」才会自动解锁！

### 第二步：开启文明 6 联机辅助

1. **房主**：在文明 6 中创建 **局域网** 房间，点击 **启动房主联机桥接**。
2. **加入者**：选择已在线且测试通过的房主，点击 **启动加入者联机辅助**；可先点 **探测房主文明6房间** 确认收到房间信息，再切回文明 6「多人游戏 → 局域网」刷新并加入。

> 联机辅助按钮严格受在线人数控制：**至少 2 人在线且连通测试通过**方可开启。
